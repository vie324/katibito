# 面接記録 運用ガイド(v0.3)

面接官3人で候補者1人と面接し、**同意を得て録画**した映像と**表情の計測結果**を、
その場にいなかった担当者も含めた全員で確認して判定するための仕組みです。

- 面接官は当日、ノートPCとカメラで録画します(録画は録画中から順次サーバーへ送られます)
- その場にいない担当者は、**録画中の面接を数秒遅れで見る**(ライブ)ことも、あとから録画・文字起こし・表情の計測・面接官の評価を見て判定することもできます
- 面接官はそれぞれ評価シートで評価します。**自分の評価を提出するまで、ほかの人の評価は見えません**(先入観を避けるため)
- **合否は人が決めます。** 表情の計測は、判定の参考資料のひとつです

---

## 1. 表情の計測について(最初に必ずお読みください)

### 何を測っているか

録画の映像から顔の形の変化を読み取り、次の数値にします。

| 指標 | 意味 |
|---|---|
| 笑顔の頻度 | 顔が映っていた時間のうち、口角が上がっていた時間の割合 |
| 笑顔の回数 | 0.4秒以上続いた笑顔の回数(1分あたり) |
| 笑顔の大きさ | 口角の上がり方が大きかった場面の平均(0〜1) |
| 眉の動き | 眉が上がっていた時間の割合 |
| 表情の変化 | 口元・頬・眉の動きの大きさのばらつき |
| うなずき | 頭の縦の小刻みな動きの回数(1分あたり、目安) |
| 表情の豊かさ(総合) | 上の指標を暫定基準で0〜100にまとめた値 |
| 参考値 | 下を向いていた割合、まばたき、頬の上がりを伴う笑顔、頭の向きの変動 |

あわせて、**注目シーン**(笑顔が大きかった場面・表情がよく動いた場面・顔が映っていない区間)と、
**質問ごとの集計**(録画中に押した質問ボタンの区切りごと)を出します。クリックすると動画のその場面に移動します。

### 何を測っていないか

- 感情(喜び・緊張・不安など)や性格、能力、意欲は**推定していません**
- 年齢・性別などの属性も推定しません
- 話した内容は**文字起こし**(サーバーの中で文字にしたもの)として記録しますが、点数にしたり分析したりはしません

### 数値を見るときの注意

表情の出方は、**個人差・年齢・その日の緊張や体調・文化的な背景・障害や発達特性**などで大きく変わります。
表情が少ないことは、能力や意欲が低いことを意味しません。次のように使ってください。

1. **数値だけで判断しない。** 合否は面接官の評価を中心に決め、表情の計測は補助的な記録として扱う
2. **気になる数値は、録画のその場面を見て確かめる。** 注目シーンや質問ごとの集計から、映像に飛べます
3. **数値の低さを減点の理由にしない。** 「笑顔が少ないから不合格」のような使い方はしない
4. **計測の信頼度が「低」のときは数値を使わない**(顔が小さい・顔が映っていない時間が長い、など)

数値の基準は、まだキャリブレーション(自分たちのデータでの調整)をしていない**暫定基準**です。
面接を10件以上記録すると、各指標に「これまでの面接の中での位置」が表示されます。
年齢を入力しておくと、**同じ年代(9歳以下・10〜12歳・13〜15歳・16〜18歳・19歳以上)の面接と比べる**こともできます
(表情の出方は年齢で大きく違うため、同じ年代が10件以上あれば、そちらが先に表示されます)。
比較に使う値は、どの面接の値かが分からない形でだけ表示します。

## 2. 用意するもの

| 場所 | 用意するもの |
|---|---|
| サーバー | 録画とデータを保管する場所(「3. サーバーの設置」を参照) |
| 面接室 | ノートPC(**Google Chrome**)、**USB の外付けカメラ**、カメラを立てるスタンドや三脚、顔が明るく映る照明 |
| 面接官・判定する人 | 評価・ライブ視聴に使う端末(パソコン・スマートフォン・タブレットのどれでも可) |

- 外付けカメラをおすすめする理由: ノートPCの内蔵カメラを候補者に向けると、画面も候補者に見えてしまい気が散るためです。外付けカメラなら、PCの画面は面接官側に向けられます
- 録画の端末は1時間あたり約0.5GB(標準画質)を一時的に保存します。空きが数GB以上あることを確認してください
- スマートフォンやタブレットでは、ブラウザの「ホーム画面に追加」でアプリのように使えます(録画・評価のデータは端末に保存しません)

## 3. サーバーの設置

### A. クラウドの仮想サーバーで動かす(推奨)

ConoHa VPS・さくらのVPS・AWS Lightsail などの Linux サーバーに、Docker で設置します。
HTTPS(暗号化)の証明書は自動で取得されます。カメラを使うには HTTPS が必須です。

**目安のスペック:** 2〜4 CPU / メモリ 4GB / ディスク 100GB 以上(面接100件 × 30分 ≒ 25GB。保存期間の設定で自動的に削除されます)。
文字起こしを使う場合は CPU が多いほど早く終わります(4 CPU で、録画の長さの半分〜同じくらいの時間)。

1. ドメイン(例: `interview.example.jp`)の DNS の A レコードを、サーバーの IP アドレスに向ける
2. サーバーに Docker をインストールし、80番・443番ポートを開ける
3. このリポジトリを置いて、設定ファイルを作る
   ```bash
   git clone <このリポジトリ> katibito
   cd katibito/deploy
   cp .env.example .env
   # .env の DOMAIN を自分のドメインに書き換える(メールを使う場合は SMTP の設定も)
   ```
4. 起動する
   ```bash
   docker compose up -d --build
   docker compose logs app     # 「初期設定コード: XXXX-XXXX」が表示される
   ```
5. ブラウザで `https://<ドメイン>/` を開き、「4. 初期設定」に進む

データ(録画・評価)は `deploy/data/` に保存されます。
アプリは root ではない専用ユーザー(UID 1000)で動き、初回の起動時に `deploy/data/` の所有者をそのユーザーに変更します。
Docker 版には、再生用 MP4 を作る ffmpeg と、文字起こしの whisper.cpp が入っています。

### B. 手元のパソコンで試す

Node.js 22 以上が必要です。

```bash
npm ci
npm run build
npm start            # http://localhost:8787
```

起動したときに表示される「初期設定コード」を使って初期設定をします。
この方法では、**同じパソコンのブラウザ(localhost)からしか**カメラを使えません(ほかの端末からカメラを使うには HTTPS が必要です)。

### 設定できる環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 8787 | 待ち受けるポート |
| `DATA_DIR` | `./data` | データの保存先 |
| `TRUST_PROXY` | 0 | リバースプロキシ(Caddy 等)の後ろで動かすときは 1 |
| `APP_URL` | (なし) | 通知・メールに載せる URL(例 `https://interview.example.jp`)。通知を使う場合は設定してください |
| `INITIAL_SETUP_CODE` | (自動生成) | 初期設定コードを固定したい場合 |
| `MAX_CHUNK_MB` | 32 | 1回に受け取る録画データの上限 |
| `SESSION_DAYS` | 14 | ログインの有効日数 |
| `TRANSCODE` | auto | 0 にすると再生用 MP4 を作らない |
| `FFMPEG_PATH` | ffmpeg | ffmpeg の場所 |
| `TRANSCRIBE` | auto | 0 にすると文字起こしをしない |
| `WHISPER_CLI` | whisper-cli | whisper.cpp の実行ファイル |
| `WHISPER_MODEL` | small-q5_1 | 文字起こしのモデル(`base-q5_1` なら軽く速いが精度は下がる) |
| `WHISPER_MODELS_DIR` | `DATA_DIR/models` | モデルの置き場所(なければ初回に自動で取得、約190MB) |
| `WHISPER_THREADS` | CPU 数 − 1 | 文字起こしに使う CPU の数 |
| `SMTP_HOST` | (なし) | メールを送る SMTP サーバー。未設定ならメールは送りません |
| `SMTP_PORT` | 587 | 465 なら最初から TLS、それ以外は STARTTLS(暗号化できない相手には送りません) |
| `SMTP_SECURE` | 0 | 1 にすると最初から TLS(465 番) |
| `SMTP_USER` / `SMTP_PASS` | (なし) | SMTP の認証 |
| `MAIL_FROM` | (なし) | 差出人(例 `面接記録 <noreply@example.jp>`)。未設定ならメールは送りません |

### 文字起こし(サーバーの中で処理)

録画が届くと、サーバーの中の whisper.cpp で音声を文字にします(外部のサービスには送りません)。
最初の1回はモデル(約190MB)をインターネットから取得します。「設定 > 機能」の「いまモデルを取得する」で先に取得しておくこともできます。
インターネットに出られないサーバーでは、モデル(`ggml-small-q5_1.bin`)と VAD のモデル(`ggml-silero-v5.1.2.bin`)を
`WHISPER_MODELS_DIR` に置いてください。

### メール(SMTP)

`SMTP_HOST`・`MAIL_FROM` などを設定すると、メールでお知らせを送ります(各自が「アカウント」で受け取る内容を選びます)。
Google Workspace・Microsoft 365・レンタルサーバーの SMTP などが使えます。設定したら「設定 > 機能」の「自分にテストメールを送る」で確認してください。
メールには、候補者の表示名・日時・リンクだけを載せます(評価の内容や数値は載せません)。

### スマートフォンでの再生(MP4 の自動作成)

サーバーに ffmpeg があると(Docker 版には入っています)、録画を受け取ったあとに
**どの端末でも再生できる MP4(H.264)** を自動で作ります。iPhone / iPad の Safari でも確認できます。
変換は録画の長さの数分の1〜同程度の時間がかかり、終わるまでは元の形式(WebM)で再生します。

### バックアップ

`data/` ディレクトリをまるごとコピーすれば、すべてのデータ(録画・評価・応募書類・設定・操作ログ)をバックアップできます。

```bash
cd katibito/deploy
tar czf backup-$(date +%Y%m%d).tgz data/
```

バックアップにも録画が含まれます。保管場所の管理と、保存期間を過ぎたバックアップの削除を忘れないでください。

### 更新

```bash
cd katibito && git pull
cd deploy && docker compose up -d --build
```

v0.2 からの更新では、データはそのまま使えます(v0.2 の評価項目・質問は「標準」の評価シートに自動で移ります)。

## 4. 初期設定

1. **管理者を作成** — 初期設定コード・団体名・管理者の氏名・ログインID・パスワードを入力します
2. **アカウント** — 自分の**2段階認証**(下記)と、**メールアドレス・受け取るお知らせ**を設定します
3. **設定 > 基本**
   - 団体名、**連絡先**(同意文・合否通知書の「お問い合わせ先」に入ります)
   - 「自分の評価を提出するまで、ほかの評価者の評価とメモを表示しない」(おすすめ: オン)
   - **面接官が見られる面接**: すべて / 担当の面接だけ(面接官に選ばれた面接と、自分が登録した面接)
   - 録画の画質(会場の回線が細い場合は「軽量」)
   - 通知先(Slack / Google Chat の Incoming Webhook。録画の共有・評価の提出・判定の確定・ライブ開始などを通知します)
4. **設定 > 評価シート** — 評価項目(1〜5で評価、項目ごとの**重み**)・質問と**時間の目安**・**合格の目安**(合計点)の組み合わせ。
   一般枠・推薦枠など、面接の種類ごとに用意できます。登録済みの面接は登録時の内容を使うため、あとで変えても過去の評価は変わりません
5. **設定 > 機能** — 文字起こし、メールのお知らせ(評価の催促・前日のお知らせ)、映像の透かし、**管理者の2段階認証の必須化**
6. **設定 > 同意文** — 候補者・保護者に見せる文面です。**自分たちの運用に合わせて必ず確認・修正してください**
7. **設定 > 通知書** — 合否通知書の文面(合格・不合格・保留)。`{宛名}` `{候補者名}` `{団体名}` `{面接日}` `{連絡先}` などを差し込めます
8. **設定 > 保存期間** — 判定が出てから録画を消すまでの日数(既定 90日)、応募書類を消すまでの日数(既定 365日)など
9. **設定 > ユーザー** — 面接官を追加し、ログインIDと初期パスワードを本人に伝えます(メールアドレスも登録できます)

権限は2種類です。

| 権限 | できること |
|---|---|
| 管理者 | すべて(設定・ユーザー管理・判定・削除・同意の取り消し・合否通知書・データの書き出し・操作ログ・CSV出力) |
| 面接官 | 面接の登録・録画・ライブ視聴・評価・メモ・応募書類の添付・同意のリンクの作成・記録票の印刷 |

### 2段階認証(おすすめ)

「アカウント > 2段階認証」で設定すると、ログインのときにパスワードに加えて、スマートフォンの認証アプリ
(Google Authenticator・Microsoft Authenticator など)に表示される6桁の確認コードが必要になります。

1. 「設定を始める」→ 認証アプリで QR コードを読み取る
2. アプリに表示された6桁の数字を入れて「有効にする」
3. 表示された**予備のコード**(10個)を印刷するか書き写して保管する。スマートフォンが使えないとき、1回ずつ確認コードの代わりに使えます

管理者は録画・評価・設定のすべてに触れられるため、「設定 > 機能 > 管理者に2段階認証を必須にする」をおすすめします
(オンにすると、未設定の管理者は設定するまでほかの画面を使えません)。
スマートフォンをなくした人は、管理者が「設定 > ユーザー > 変更 > 2段階認証を解除する」で解除できます。

## 5. 面接の流れ

### ① 事前: 面接を登録する

「面接一覧 > 面接を登録」で、候補者の表示名(イニシャルや受付番号でも可)・年齢・**面接の段階**(一次面接など)・面接日時・**面接官**・**評価シート**を登録します。
質問と時間の目安は評価シートから入り、面接ごとに変えられます。
年齢が18歳未満なら自動で「未成年」になり、録画には保護者の同意が必要になります。

- **二次面接など**: 前の面接の詳細画面で「次の面接を登録」を押すと、同じ候補者の面接としてまとめられます(詳細画面に「ほかの回の面接」が出ます)
- **応募書類**: 願書・作文などの PDF や画像を、詳細画面の「応募書類」から添付できます(1件 20MB まで)
- **予定**: 「予定」で週ごとの面接を確認できます。「この週を .ics で保存」「カレンダーに追加」で、各自のカレンダーアプリに取り込めます
- **前日のお知らせ**: メールを設定していれば、前日の夕方(設定の時刻)に担当の面接官へ届きます

### ② 事前: オンラインで同意を得る(任意)

面接の前に、保護者のスマートフォンなどで同意を回答してもらえます。

1. 詳細画面の「事前のオンライン同意」で有効期限を選び「同意のリンクを作る」
2. 表示されたリンク(または QR コード)を、メール・メッセージアプリ・紙に印刷するなどして保護者に送る。
   **リンクはこの画面でしか表示できません**(なくしたら作り直してください)。リンクを知っている人は誰でも回答できるため、本人・保護者以外に知られないようにしてください
3. 保護者が回答すると、この面接の同意として記録されます(録画と表情の計測を別々に。メールを設定していれば管理者に届きます)

当日の撮影の前にも、口頭で確認してください。不要になったリンクは「取り消す」で使えなくなります。

### ③ 当日: 機材を置く

```
        [候補者]
           │  ← 1〜1.5m
   ┌───────┼───────┐
 [面接官] [カメラ] [面接官]      カメラは面接官の間から、候補者の顔の高さに向ける
           [面接官]              ノートPCの画面は面接官側に向ける
```

- 候補者の顔が、映像の高さの **12%以上**(できれば20〜40%)で映るようにします
- 窓を背にした逆光を避け、顔の正面から光が当たるようにします
- 面接官の顔が映り込んでもかまいません(候補者の顔だけを計測します)

### ④ 同意を得る

面接の詳細画面で「同意を取得して録画」を押します(オンラインで同意済みなら「録画を開始」)。

- **この画面で同意を得る**: 画面を候補者(と保護者)に向けて文面を読んでもらい、チェックと氏名を入力してもらいます
- **紙の同意書で取得済み**: 紙の同意書(`docs/consent-form.md` を印刷)で同意を得た場合に、内容を転記します

録画と表情の計測は**別々に**同意を取ります(録画だけ同意、もありえます)。
同意が得られない場合は「録画しないで面接する」を選びます。**同意しないことで不利に扱わないでください**(同意文にもそう書いています)。

### ⑤ 撮影の準備

- カメラ・マイクを選びます(外付けカメラを選ぶ)
- 映像の中で、**緑の枠が「候補者」** です。面接官の顔が選ばれている場合は、候補者の顔をクリックします
- 確認項目(候補者の顔・顔の大きさ・明るさ・マイク)がすべて ● になるよう、カメラの位置と照明を調整します

### ⑥ 録画

「録画を開始」を押すと録画が始まります。

- 質問をするときに、その**質問のボタン**を押します(キーボードの N で次の質問)。質問ごとの集計と文字起こしの見出しに使います。
  画面に、いまの質問の経過時間と時間の目安が出ます。押し忘れても、あとから区切りを追加できます
- 印象に残った場面で「**★ 印をつける**」(B キー)
- 「プレビューを隠す」で、画面の映像を隠せます(録画は続きます)
- **その場にいない人からのメッセージ**(「もう少し志望理由を聞いてください」など)が届くと、画面の右に表示されます
- 終わったら「録画を終了」

録画は2秒ごとにこの端末に保存され、**録画中から順次サーバーに送られます**。
回線が切れても録画は止まらず、つながると続きから送ります。ブラウザが落ちても、次にアプリを開くと残りを送ります。

### ⑦ ライブで見る(その場にいない人)

録画が始まると、面接の詳細画面(一覧では「● ライブ」)で、**数秒遅れのライブ**で見られます(メールを設定していれば「面接が始まりました」が届きます)。

- 「この場面にメモ」で、見ている場面の時刻つきのメモを残せます
- 「面接室に送る」で、録画している端末の画面にメッセージを出せます(面接官への質問の追加の依頼など)
- 映像はサーバーに届いた分から再生するため、回線の状況によって遅れが大きくなることがあります

### ⑧ 送信の完了を確認する

終了画面で「送信が完了しました」と出るまで、**端末の電源を切らないでください**。
画面上部の「録画を送信中」から、送信の状況を確認できます。

### ⑨ 評価する(各面接官)

面接の詳細画面の右側で、評価項目ごとに1〜5を選び、総合評価(合格・保留・不合格)とコメントを入力して「提出する」を押します。
**合計点**(評価シートの重みつきの平均)が自動で出ます。

- 提出するまで、ほかの面接官の評価とメモは表示されません
- 判定が確定するまでは修正できます。ただし提出後の修正は、回数と日時が評価に表示されます
  (ほかの面接官の評価が見える状態で修正した場合は、そのことも表示されます)
- 録画を見ながら「メモ」タブで気づいたことを書くと、その時刻と一緒に残ります
- メールを設定していれば、録画が共有されたときと、未提出のまま時間がたったとき(24時間おき・最大3回)にお知らせが届きます

### ⑩ 判定する(管理者)

全員の評価がそろうと「判定待ち」になり、通知が届きます。
詳細画面の「判定」で、評価の集計(票数・合計点の平均と**合格の目安**・項目ごとの平均と幅)と表情の計測(参考)を確認し、合格・保留・不合格を確定します。
評価が分かれている項目(最小と最大の差が2以上)は「意見が分かれています」と表示されます。

- **比較**: 「比較」で、候補者を合計点・項目ごとの平均・票・表情の指標で並べ替え、期間・段階・評価シート・判定で絞り込めます
- **記録票**: 詳細画面の「記録票」で、面接の記録を A4 で印刷・PDF に保存できます
- **合否通知書**(判定後): 判定に合わせた文面で、宛名(保護者・本人)を差し込んだ通知書を印刷できます。文面はその1通だけ手直しもできます

## 6. 録画の確認のしかた(その場にいなかった方へ)

詳細画面の左側で確認します。

1. **注目シーン** — 笑顔が大きかった場面、表情がよく動いた場面、顔が映っていない区間。クリックでその場面へ
2. **質問ごと** — 質問の区切りごとの笑顔・眉の動き・うなずきなど。どの質問で表情が動いたかが分かります
3. **文字起こし** — 話した内容を、録画の時刻つきで読めます。押すとその場面へ。ことばで探すこともできます。
   自動の文字起こしのため、聞き取りの誤りや、話した人の区別がないことに注意してください
4. **メモ** — 面接官のメモ(時刻つきのメモはクリックでその場面へ)
5. **タイムライン** — 上から、質問の区切り・笑顔・眉・表情の動き・頭の縦の動き・音量・顔の計測(赤は顔が映っていない区間)
6. **表情の豊かさ・各指標** — 下部の要約。**計測の信頼度**を必ず確認してください

- 再生速度は ×1.5・×2 に変えられます
- 「**この場面のリンク**」で、その時刻から再生するリンクをコピーできます(ログインできる職員どうしの共有用)
- 映像には、見ている人の名前と日時が薄く表示されます(画面の撮影や持ち出しを防ぐため。設定で切り替え)
- 画面上部の「さがす」で、見られる面接の候補者名・メモ・評価のコメント・文字起こしをまとめて探せます

## 7. データの取り扱い

### 保存場所と見られる人

- 録画・文字起こし・計測結果・評価・応募書類は、設置したサーバーの `data/` にだけ保存されます(外部のサービスには送りません。メールを使う場合は、お知らせのメールだけが SMTP サーバーを通ります)
- 見られるのは、ログインできる職員(管理者・面接官)だけです。「担当の面接だけ」の設定では、面接官は担当の面接だけを見られます
- 表情の計測は、録画した端末のブラウザの中で行います(映像を解析サービスに送ることはありません)
- 文字起こしは、サーバーの中で行います
- 録画した端末には、送信が終わるまで録画が一時的に残ります。サーバーでの処理が終わり再生できるようになった時点で、端末から削除されます

### 保存期間と自動削除

- 判定が確定してから **90日**(設定で変更可)たつと、録画の映像・文字起こし・顔の時系列データを自動で削除します
- 判定が出ないまま、サーバーが録画を受け取ってから **180日**(設定で変更可)たった録画も削除します
  (起点はサーバーが受け取った日時です。取り込んだ動画の撮影日や、端末の時計は使いません)
- 判定が確定してから **365日**(設定で変更可)たつと、応募書類(添付ファイル)を削除します
- 表情の集計(数値)・評価・判定の記録は、選考の記録として残ります
- 削除は6時間ごとに自動で行います。「設定 > 保存期間」からすぐに実行することもできます

### 同意の取り消し・削除の依頼があったとき(管理者)

詳細画面の「同意の取り消し」から、次のどちらかを選びます。

- **表情の計測だけ取り消す** — 計測データを削除し、録画は残します
- **録画も含めてすべて取り消す** — 録画・文字起こし・計測データを削除します

評価・メモ・判定・応募書類も含めて完全に消す場合は、詳細画面の「削除」を使います(元に戻せません)。

### 開示を求められたとき(管理者)

詳細画面の「書き出す」で、その候補者の面接の記録・同意・評価・メモ・録画・表情の集計・文字起こし・応募書類を
1つの ZIP ファイルにまとめて保存できます(同じ候補者のほかの回の面接も含められます)。
個人情報を含むため、受け渡しの方法と、渡したあとの廃棄に注意してください。書き出したことは操作ログに残ります。

### 操作ログ

ログイン、面接の閲覧、録画の再生・ライブ視聴、検索、評価の提出、判定、書き出し、削除、2段階認証の設定などを記録しています(「設定 > 操作ログ」)。
操作ログには候補者の氏名は記録せず、面接の ID で記録します(検索したことばは記録します)。

### CSV 出力

「設定 > データ出力」から、面接の一覧(評価の集計・判定・表情の主な数値)を CSV で出力できます。
「比較」の画面からは、絞り込んだ面接だけを出力できます。個人情報を含むため、取り扱いに注意してください。

### 個人情報の扱いについて

録画した映像は個人情報です。運用する団体として、少なくとも次の点を確認してください(法的な要件は、団体ごとに専門家に確認してください)。

- 利用目的(選考のため・その場にいない担当者の確認のため・文字起こし)を本人・保護者に示し、同意を得ていること(同意文)
- 未成年の場合は保護者の同意を得ていること
- サーバー・バックアップ・録画端末の管理(アクセスできる人の限定、2段階認証、退職者のアカウントの無効化)
- 保存期間を決めて、過ぎたものを削除していること
- 同意の取り消し・削除・開示の依頼に対応できる窓口(同意文の連絡先)

## 8. よくある質問・困ったとき

**カメラが映らない**
- アドレスバーのカメラのアイコンから、カメラとマイクを「許可」にしてください
- ビデオ会議アプリなど、ほかのアプリがカメラを使っていないか確認してください
- `https://` で開いているか確認してください(`http://` ではカメラを使えません。localhost を除く)

**「候補者の顔」が ● にならない**
- 候補者の顔が映像の中央付近に、十分な大きさで映っているか確認してください
- 逆光(窓を背にする)になっていないか確認してください
- 映っている顔が別の人に選ばれていれば、候補者の顔をクリックしてください

**計測の信頼度が「低」になった**
- 顔が小さく映っている、顔が映っていない時間が長い、録画中に別の画面に切り替えた、などが原因です。画面に表示される理由を確認してください
- 録画は残っているので、映像そのもので確認してください。管理者は「表情を計測し直す」で、録画から計測をやり直せます

**録画の送信が終わらない**
- 画面上部の「録画を送信中」を押して状況を確認してください
- 「接続待ち」は回線が切れています。つながると自動で再開します
- 「仕上げ中」はサーバーが録画を処理しています。再生できるようになった時点で端末内のデータが消え、表示も消えます
- 「送信できません」は「再試行」を押してください。解決しない場合は管理者に連絡してください。端末内の録画は、「破棄」を押すまで消えません
  - 「届いている部分で完了」— 端末内のデータの一部が失われたとき、失われた位置の手前までで録画を完了します
  - 「送り直す」— サーバー側で失敗扱いになった録画(長期間送信できなかった等)を、新しい録画として最初から送り直します

**ライブの映像が止まる・遅れる**
- 録画している端末の回線が細いと、サーバーに届くのが遅れます。録画そのものは端末に残り、あとで全部届きます
- 画面を開き直すと、最新の場面から見直せます

**文字起こしが出ない**
- 「設定 > 機能」で、文字起こしがこのサーバーで使えるか確認してください(Docker 版では使えます)
- 録画の長さによって時間がかかります(処理中は「文字起こしをしています」と表示されます)
- 失敗した場合、管理者は文字起こしのタブの「やり直す」で再実行できます

**メールが届かない**
- 「アカウント」でメールアドレスと受け取る内容を確認してください
- 管理者は「設定 > 機能 > 自分にテストメールを送る」で SMTP の設定を確かめられます。迷惑メールのフォルダも確認してください

**スマートフォンをなくした(2段階認証)**
- 予備のコードがあれば、確認コードの代わりに使ってログインし、「アカウント」で設定し直してください
- 予備のコードもなければ、管理者に「2段階認証を解除する」を依頼してください

**録画が「処理に失敗」になった(管理者)**
- 詳細画面の「再処理する」で、受け取ったデータから録画を作り直せます
- サーバーの空き容量が足りないことが原因の場合は、先に容量を空けてください(処理中は録画の約3倍の空きが必要です)

**録画がスマートフォンで再生できない**
- サーバーで再生用の MP4 を作成中の可能性があります。しばらく待ってから開き直してください
- それでも再生できない場合は、パソコンの Chrome / Edge で確認してください

**別のカメラ(ビデオカメラ・スマートフォン)で撮った動画を使いたい**
- 面接の詳細画面の「動画を取り込む」から取り込めます。取り込むときに、そのパソコンで表情を計測します(動画の長さの数分の1〜同程度の時間がかかります)

**パスワードを忘れた**
- 管理者が「設定 > ユーザー > 変更」でパスワードを再設定できます

**動作確認用のデモ画面**
- `/demo` は、営業・説明用の「行動シグナル解析デモ」です(ログイン不要。データは保存されません)
- Vercel などの静的ホスティングで公開しているアドレスでは、運用版(サーバーが必要)の代わりにこのデモが表示されます。
  運用版は「3. サーバーの設置」の方法で設置したサーバーのアドレスで使ってください
